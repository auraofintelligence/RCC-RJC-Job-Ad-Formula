# Platform field map for manual copy and paste

Research checked **22 October 2026**, using public official help pages without signing in. This is a field map for preparing copy, not an automated posting integration. Account, region, device and feature rollouts can change the form. A documented input is not proof that the current Australian form marks it with a required asterisk; uncertainties are stated below.

## LinkedIn Jobs: native job listing

Keep this separate from a LinkedIn feed post. Supply individual setup values followed by one copyable **Description** block. The current desktop guide starts with **Job title**, then the description, then **Job settings**; the mobile guide groups the flow into **Job Details**, **Job Description**, and **Job Settings**. A free listing must be associated with a LinkedIn company Page. Skills controls may be absent in LinkedIn's current rollout. [L1]

| Field or setting | Input type and verified choices | Status and builder treatment |
| --- | --- | --- |
| Job title | Text; a recognisable standard title. Standardised-title suggestions are documented in Recruiter. | Core native input. Output its value separately; do not add location, benefits or a sales headline to it. Current free guide explicitly asks for it. [L1, L2, L6] |
| Company | Company/Page selection; LinkedIn documents choosing the company from a dropdown. | Free-post Page association is required. Output company name plus “select the matching LinkedIn Page”; do not invent a Page. [L1, L3] |
| Workplace type | Choice: **On-site**, **Hybrid**, **Remote**. | Core input confirmed. Exact current free-form widget and required marker were not inspected. Recruiter explicitly uses a dropdown. [L2, L4, L6] |
| Job location | Location input; select the genuine work location rather than accepting a profile-location default. | Core input confirmed; current free-form required marker not independently inspected. Non-Recruiter guidance says only city-level address is shown, location must be entered in English, and continents/multinational regions larger than countries are unsupported. [L2, L4] |
| Job type | Employment-type choice; this input name is documented for non-Recruiter jobs. | Core input confirmed, exact free-form option list/required marker not verified. Recruiter calls it **Employment type**. Preserve Australian casual/fixed-term details in Description rather than inventing a native Casual option or silently mapping employment status. [L2, L6] |
| Description / Job Description | Long text editor; paste the completed ad body. | Separate copy block. Include duties, essential/desirable criteria, hours/roster, confirmed pay/benefits and application instructions. A current free-form character limit was not verified. [L1, L3] |
| Skills | Conditional skills-entry/selection control. | Do not make a universal required field: LinkedIn explicitly says some users will not see this option. Suggested skills can be supplied separately if useful, without a claimed universal count limit. [L1] |
| Manage applicants / applicant collection | Select collection through LinkedIn or route applicants to an external website; email address for applicant updates, or application URL. | Supply the employer's chosen setting and exact destination. An email entered for LinkedIn updates is not automatically the public “email your CV” destination. Applicant-options guidance says the collection method cannot be changed after posting. [L1, L5] |
| Screening questions | Optional screening configuration. | Native feature exists; candidate screening is outside this builder's writing scope. Do not generate automatic screening or rejection decisions. [L1] |
| Rejection settings | Optional filtering/rejection configuration. | Outside builder scope. [L1] |
| #Hiring frame | Profile-frame setting. | Optional promotion of hiring status; no ad-copy field required. [L1] |
| Free / Promoted | Publication/payment choice. | Employer decides in LinkedIn. No budget, card information or paid promotion generated by this builder. [L1] |

Jobs are posted from an individual member account and associated with the company's Page; do not tell employers to create a personal account named after their business. [L7]

### Recruiter is a different form

Recruiter/Hiring Assistant documentation names **Company**, **Job title**, **Seniority level**, **Employment type**, **Company industry**, **Job function**, **Workplace type**, **Job description**, **Job location**, **Compensation**, **Application method**, and **Add to a project**. It explicitly documents dropdowns and up to three industries/functions. These are evidence for that product, not proof that every field appears in a free Jobs form. Its application choices are **Recommended: Easy Apply** and **Direct applicants to an external site to apply**. [L6]

Recruiter's edit guidance lists employment types Full-time, Part-time, Contract, Temporary, Volunteer and Internship. Treat that as a documented Recruiter list, not a verified exhaustive Australian free-form list. [L8]

### Verified constraint scopes

| Constraint | Verified scope | Do not generalise to |
| --- | --- | --- |
| 3,000 characters | Ordinary LinkedIn feed post. [L9] | Native Jobs Description. |
| 10,000 characters | Job description when posting through **LinkedIn Recruiter**. [L10] | Every free Jobs editor, feed post or API. |
| Minimum 100 description characters | LinkedIn's customer **XML ingestion guide**. [L11] | Native desktop/mobile manual forms. |
| No verified current native-free title/description maximum | Public sources reviewed did not establish it. | Do not label an editorial target as a platform limit. |

## LinkedIn feed: ordinary social post

This is a single post body, not a native Jobs field set. Its purpose can be to share the vacancy and link to the application page or native job listing. [L9]

| Actual control or label | Type | Builder output |
| --- | --- | --- |
| Start a post | Composer entry point. | Instruction only. |
| Share your thoughts… / What do you want to talk about? | Post text area; wording differs between official help flows. | One copyable post, at most 3,000 characters including its application link. |
| Who can see your post? | Audience choice: Anyone, Connections only, or Group in the documented flow. | Employer chooses; not part of pasted copy. |
| Who can comment on your post? | Choice: Anyone, Connections only, or Off. | Employer chooses. |
| Media / other attachments / schedule | Optional controls. | No invented required headline, summary, skills or job-type dropdowns for an ordinary text post. |

The composer also offers a **Job** action. That enters a hiring workflow; it does not make every ordinary social post a native Jobs listing. [L9]

## Facebook: ordinary Page or community-group post in Australia

Prepare **one copyable post body** with vacancy facts and its application route embedded in the text. Do not create native job-title/pay/employment-type field blocks for this ordinary-post destination. Page and group posting controls differ; the exact current Australian Page composer was not inspected while logged in.

| Surface/control | Type and evidence | Builder treatment |
| --- | --- | --- |
| Ordinary Facebook text update | Meta's generic sharing guide documents **What's on your mind, [Name]?**, text, optional media, audience and **Post**. This guide is for Feed sharing, not proof of exact Page labels. [F1] | One body; do not promise a Page-specific placeholder label. |
| Group composer | **Write something...** and **Add to your post** are documented in Meta's group guide. Group admins can restrict some post formats. [F2, F3] | One group-post body; user checks rules and approval. |
| Photo/video, tagging, location and other additions | Optional composer features documented by Meta. [F1, F3] | Optional publishing steps, not essential job-ad form fields. |
| Participant/post approval | Group-controlled process. [F4] | Warn that submission may await approval; do not claim successful publication. |

No current official character limit for an ordinary Australian Page/group text post was verified. A short length target is an editorial choice. Paid advertising/boosting is a separate optional workflow outside this builder. A dedicated Australian Jobs listing flow was not verified: Meta's 2025 Jobs relaunch announcement explicitly concerns the US. [F5]

## Short vacancy copy

“Short vacancy post” is an output format, not a platform with a verified native form. Supply one self-contained block containing title, area, employment basis/hours, core opportunity and exact next step. Any word target is an editorial target. If the employer chooses a specific destination later, apply that destination's verified limits rather than inventing universal fields.

## Verification boundary

The official descriptions establish product inputs and selected labels, not a live Australian account's complete required-field validation. No user credentials were requested, no account was accessed, and no job was submitted. Exact order, required asterisks, selectors and limits should be rechecked against the employer's visible form before making stronger platform-validation claims.
