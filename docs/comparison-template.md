## Repeatable scenarios

1. **Short facts with gaps:** omit hours and a required social destination. Check draft labels, visible gaps and whether the AI asks only necessary questions. A SEEK-only run does not need an external destination.
2. **Complete existing ad pasted:** include all factual details in the ad with sparse form answers. Check reuse, no repeated full questionnaire, and no lost conditions. Repeat with one deliberate conflicting form value; require a visible conflict rather than silent resolution.
3. **SEEK plus social:** provide a social application email/link. Check SEEK uses its configured Apply route while Facebook/feed/short copy retains the supplied social destination.
4. **Exact channel selection:** select one channel, then a combination. Check no unwanted outputs and no missing selected ones.
5. **Optional SEEK selling points:** test an unknown/unsupported product and a product confirmed to support three points. Check product caveats, separate fields and per-field limits.
6. **LinkedIn format:** run Jobs listing and feed post separately. Check structured listing fields/setup notes versus a single post block and appropriate application route.
7. **Style and factual boundaries:** select joyful responsible abundance with limited benefits and incomplete pay checks. Check truthful warmth and clear agreements without invented perks, guarantees or a declaration of compliance.

Use the same facts for both methods in each scenario. If a method requires extra answers, record them and supply identical factual answers when comparable; count the effort. These are proposed tests, not completed trials.
